## 1. Identité de marque

### Nom

**Collector**

### Positionnement

Collector est une plateforme française dédiée à l'achat, la vente et l'échange d'objets de collection entre particuliers.

La marque s'adresse aux passionnés d'objets rares, originaux, nostalgiques ou liés à la culture populaire.

Collector ne se positionne pas sur :

* le luxe ;
* les objets de collection haut de gamme ;
* la brocante traditionnelle ;
* les antiquités.

L'identité doit plutôt évoquer :

> **La découverte d'un objet rare qui rappelle un souvenir.**

### Valeurs

* **Passion** — des objets choisis pour leur histoire et leur intérêt.
* **Nostalgie** — faire revivre des souvenirs et des émotions.
* **Rareté** — mettre en avant des pièces difficiles à trouver.
* **Communauté** — connecter les collectionneurs entre eux.
* **Authenticité** — favoriser les échanges entre particuliers.
* **Accessibilité** — rendre la collection accessible au plus grand nombre.

# 2. Logo

## Logo principal

Le logo principal associe :

* une **étiquette de collection** ;
* une **étoile**, symbole de rareté ;
* un **point**, rappelant le système d'étiquette ;
* le nom **Collector**.

L'étiquette représente à la fois l'objet de collection et son identification.

L'étoile représente la découverte d'une pièce particulière, rare ou recherchée.

## Zone de protection

Une zone libre doit être conservée autour du logo.

La distance minimale recommandée correspond à environ **la hauteur du trou de l'étiquette**.

Aucun texte, bouton, photographie ou autre élément graphique ne doit entrer dans cette zone.

---

### Logo complet

Taille minimale recommandée :

**120 px de largeur sur écran**

### Symbole seul

Taille minimale recommandée :

**24 × 24 px**

Pour les très petites tailles, privilégier le symbole seul.

# 3. Palette de couleurs

L'identité repose sur trois couleurs principales.

## Couleur principale — Charbon

**#20252B**

Utilisation :

* texte ;
* logo ;
* titres ;
* navigation ;
* éléments structurants ;
* fonds sombres.

Le charbon remplace le noir pur afin de conserver une identité plus chaleureuse.

---

## Couleur secondaire — Rouge vintage

**#E85D3F**

Utilisation :

* éléments importants ;
* boutons principaux ;
* étoiles ;
* liens actifs ;
* badges ;
* éléments graphiques ;
* appels à l'action.

Cette couleur apporte l'énergie et rappelle les affiches et objets vintage.

---

## Couleur de fond — Crème

**#F3E8D0**

Utilisation :

* arrière-plans ;
* cartes ;
* éléments du logo ;
* supports imprimés ;
* zones mettant en avant le contenu.

Le crème apporte la dimension nostalgique et évite une identité trop froide ou technologique.

---

| Nom           | HEX       | Utilisation            |
| ------------- | --------- | ---------------------- |
| Charbon       | `#20252B` | Texte / structure      |
| Rouge vintage | `#E85D3F` | Accent / CTA           |
| Crème         | `#F3E8D0` | Fonds                  |
| Blanc         | `#FFFFFF` | Interface / contraste  |
| Gris clair    | `#E5E1DA` | Bordures / séparateurs |
| Gris moyen    | `#6B7280` | Texte secondaire       |

### Règle d'utilisation

La couleur **#E85D3F** doit rester une couleur d'accent.

Elle ne doit pas être utilisée massivement sur toute l'interface.

Exemple :

```text
Fond principal       → #FFFFFF
Texte                → #20252B
Texte secondaire     → #6B7280
Bouton principal     → #E85D3F
Fond secondaire      → #F3E8D0
```

# 4. Typographie

## Police principale

### Inter

La police **Inter** est recommandée pour l'ensemble de l'interface numérique.

Elle est :

* moderne ;
* lisible ;
* disponible sur le web ;
* adaptée aux interfaces ;
* suffisamment neutre pour laisser l'identité vintage s'exprimer à travers les couleurs et le logo.

### Hiérarchie

**Titre principal**

```text
Inter Bold
48–64 px
```

**Titre de section**

```text
Inter Bold
28–36 px
```

**Sous-titre**

```text
Inter SemiBold
20–24 px
```

**Texte courant**

```text
Inter Regular
16 px
```

**Texte secondaire**

```text
Inter Regular
14 px
```

**Boutons**

```text
Inter SemiBold
14–16 px
```

# 5. Style typographique

La communication doit être :

* simple ;
* directe ;
* chaleureuse ;
* accessible ;
* légèrement nostalgique ;
* jamais vieillotte.

### À privilégier

> Retrouvez les objets qui ont marqué votre époque.

> Une pièce rare mérite une nouvelle histoire.

> Cherchez. Trouvez. Collectionnez.

### À éviter

Un vocabulaire trop luxueux :

* prestige ;
* exclusivité ;
* haute collection ;
* patrimoine ;
* objet d'exception.

Collector doit rester proche des passionnés et des objets du quotidien.

---

# 6. Iconographie

Les icônes doivent être simples et facilement reconnaissables.

Les emoji ne sont pas utilisés, ni dans l'interface ni dans les supports de communication. Seuls des pictogrammes dessinés au trait sont employés.

### Style recommandé

* formes arrondies ;
* traits réguliers ;
* peu de détails ;
* épaisseur homogène ;
* style flat ;
* pas d'effets 3D.

### Exemples d'icônes

| Pictogramme | Signification |
| ----------- | ------------- |
| Étoile      | Objet rare    |
| Étiquette   | Collection    |
| Flèches en boucle | Échange |
| Cœur        | Favori        |
| Loupe       | Recherche     |
| Carton      | Vente         |
| Silhouette  | Profil        |
| Bulle       | Discussion    |

Les icônes doivent rester graphiquement cohérentes avec l'étiquette du logo.

---

# 7. Photographie

La photographie joue un rôle important dans l'identité de Collector.

Les objets doivent être montrés comme des **objets passionnants**, et non comme des produits de luxe.

## Style

Privilégier :

* photos authentiques ;
* objets en situation ;
* gros plans ;
* textures ;
* traces du temps ;
* emballages originaux ;
* détails des objets ;
* photos prises par les collectionneurs.

### Exemples

* une paire de baskets vintage ;
* une figurine originale ;
* une cassette vidéo ;
* un poster dédicacé ;
* une console rétro ;
* une boîte de jouet ancienne ;
* une carte à collectionner.

---

# 8. Direction artistique

L'univers graphique doit mélanger :

**Vintage + Culture populaire + Digital**

Le résultat ne doit être ni une **brocante traditionnelle**, ni une **marketplace technologique froide**, mais :

```text
        COLLECTION
             +
          NOSTALGIE
             +
          COMMUNAUTÉ
             +
          DIGITAL
```

---

# 9. UI / Design web

## Interface

L'interface doit être claire et moderne.

### Principes

* beaucoup d'espace blanc ;
* cartes avec coins légèrement arrondis ;
* bordures fines ;
* hiérarchie visuelle forte ;
* photos mises en avant ;
* boutons simples ;
* peu d'effets décoratifs.

### Rayon de bordure

```text
Petit élément : 6 px
Carte          : 10 px
Bouton         : 8 px
```

Éviter les éléments excessivement arrondis de type "bubble".

# 11. Cartes produit

Les objets mis en vente doivent être présentés sous forme de cartes.

Exemple :

```text
┌─────────────────────────┐
│                         │
│         PHOTO           │
│                         │
├─────────────────────────┤
│ [Rare]                  │
│                         │
│ Figurine Star Wars      │
│ Vintage 1995            │
│                         │
│ 120 €                   │
│                         │
│ (favori)                │
└─────────────────────────┘
```

`[Rare]` est un badge (voir section 12). `(favori)` est le pictogramme cœur (voir section 6).

La photographie doit occuper une place importante.

Le prix doit être facilement identifiable.

# 15. Réseaux sociaux

## Avatar

Utiliser uniquement le symbole de l'étiquette.

Fond recommandé :

```text
#20252B
```

Symbole :

```text
#F3E8D0
#E85D3F
```

## Publications

Les visuels doivent privilégier :

1. une photographie de l'objet ;
2. un titre court ;
3. un élément graphique Collector ;
4. une information claire.

Exemple :

```text
        COLLECTOR

        PIÈCE RARE

   La figurine qui a marqué
       toute une génération.

           [ Voir ]
```

L'étoile du logo peut accompagner la mention « Pièce rare ».

---

# 16. Logo — mauvaises utilisations

Ne pas :

* déformer le logo ;
* modifier ses proportions ;
* changer arbitrairement ses couleurs ;
* ajouter des ombres ;
* ajouter des dégradés ;
* ajouter des effets 3D ;
* incliner le logo ;
* modifier la typographie ;
* placer le logo sur un fond rendant sa lecture difficile.

### Exemples à proscrire

* logo étiré ;
* logo avec ombre ;
* couleurs modifiées ;
* logo déformé.

---

# 17. Ton de communication

Collector doit parler comme un **passionné qui partage une découverte**, pas comme une entreprise de luxe.

### Ton

**Passionné**

> Cette figurine vous rappelle quelque chose ?

**Accessible**

> Vous avez un objet qui dort dans un placard ? Il mérite peut-être une nouvelle collection.

**Nostalgique**

> Les objets que vous aviez oublié avoir gardés sont parfois les plus intéressants.

**Communautaire**

> Trouvez quelqu'un qui recherche exactement ce que vous possédez.
